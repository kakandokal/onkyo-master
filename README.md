# Onkyo Master

Приложение для Windows, которое живёт в трее и управляет AV-ресивером Onkyo по локальной сети
(протокол eISCP, TCP 60128). Разработано и проверено на TX-RZ50; список входов, зон, сетевых
сервисов и диапазоны регуляторов берутся из описания, которое отдаёт сам ресивер.

## Что умеет

- **Быстрая панель** по щелчку на значке в трее: питание, громкость и mute всегда, остальное
  выбирается в настройках — режим звучания, ночной режим, уровень центрального канала, голос
  (Vocal Enhancer), сабвуфер, что играет, сцены, входы, зоны 2 и 3. Колесо мыши над панелью меняет
  громкость.
- **Панель управления** (кнопка на быстрой панели или пункт меню): тембр и уровни каналов, тюнер,
  сетевые источники с обложкой, пульт экранного меню, HDMI-CEC, консоль ISCP, настройки.
- **Горячие клавиши** в любой программе: на вкладке «Горячие клавиши» сочетание можно назначить
  любому действию — питанию и громкости каждой зоны, каждому входу, режимам звучания, тембру,
  тюнеру, воспроизведению, кнопкам экранного меню и HDMI-CEC, сценам и своим командам ISCP.
  По желанию клавиши громкости клавиатуры управляют ресивером, пока он включён (см. ниже).
- **Сцены**: вход + громкость + режим звучания одной кнопкой или горячей клавишей.
- **Вместе с компьютером**: включать ресивер при выходе ПК из сна, выключать при засыпании.
- **Предел громкости**: выше него приложение громкость не поднимает.
- **Шкала громкости**: 0–100 или децибелы (0 дБ = 82), как настроено в Volume Display ресивера —
  по сети эту настройку узнать нельзя, поэтому она выбирается в настройках приложения.

На ресивере должен быть включён Network Standby, иначе его нельзя включить по сети.

## Требования

Windows 10 или 11, x64. Ничего, привязанного к конкретному компьютеру, в приложении нет: адрес
ресивера, сетевой адаптер, вход ПК, шкала громкости и клавиши — настройки, они хранятся отдельно на
каждом компьютере.

## Сборка

Нужен .NET 10 SDK.

```powershell
dotnet build src\OnkyoMaster\OnkyoMaster.csproj

# релиз одним exe; на компьютере, где он запускается, нужен .NET 10 Desktop Runtime (x64)
dotnet publish src\OnkyoMaster\OnkyoMaster.csproj -c Release -r win-x64 --self-contained false `
    -p:PublishSingleFile=true -p:DebugType=none -o dist

# то же, но со встроенной средой выполнения: файл больше, зато на другом компьютере ничего ставить не надо
dotnet publish src\OnkyoMaster\OnkyoMaster.csproj -c Release -r win-x64 --self-contained true `
    -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
    -p:EnableCompressionInSingleFile=true -p:DebugType=none -o dist-standalone
```

## Клавиши громкости

Галочка «Клавиши громкости на клавиатуре управляют ресивером» действует, пока ресивер включён и с ним
есть связь; в остальное время клавиши управляют громкостью Windows. Как нажатие попадает в систему,
зависит от клавиатуры и её программы, поэтому перехват идёт по двум путям:

1. **Нажатие клавиши** — обычный случай. Приложение забирает клавишу себе, Windows её не видит.
2. **Команда громкости** — так поступают программы некоторых клавиатур и пультов: вместо нажатия
   они посылают системе команду «громче». Приложение видит команду, передаёт её ресиверу и возвращает
   громкость Windows на место.

Ползунок громкости Windows и изменения громкости другими программами приложение не трогает. Если
программа клавиатуры меняет громкость Windows сама, без нажатия и без команды, такие клавиши
перехватить нельзя. При удержании клавиши громкость меняется не чаще восьми шагов в секунду.

## Запуск и командная строка

`OnkyoMaster.exe` открывает панель управления, `OnkyoMaster.exe --tray` стартует только в трее
(так его запускает автозагрузка). Повторный запуск передаёт аргументы уже работающему экземпляру —
этим удобно пользоваться из скриптов, AutoHotkey, Stream Deck:

| Команда | Действие |
| --- | --- |
| `show`, `flyout` | открыть панель управления / быструю панель |
| `power`, `power-on`, `power-off` | питание зоны |
| `vol-up`, `vol-down`, `mute` | громкость и mute зоны |
| `input:PC` | выбрать вход зоны по имени или коду |
| `mode:MUSIC`, `mode:0C` | кнопка группы режимов или режим звучания по коду |
| `bass-up`, `treble-down`, `center-up`, `sub-down`, `vocal-up` | тембр, уровни каналов и голос (`-up` / `-down`) |
| `music-optimizer`, `cinema-filter` | включить / выключить обработку |
| `cycle:dimmer`, `cycle:sleep`, `cycle:late-night`, `cycle:hdmi-out` | следующее значение настройки |
| `scene:Кино` | применить сцену |
| `raw:MVLQSTN` | любая команда ISCP |
| `exit` | закрыть приложение |

Команды зоны относятся к основной; с префиксом `z2-` или `z3-` — к Zone 2 и Zone 3 (`z2-power`,
`z3-vol-up`). Эти же команды стоят за горячими клавишами: в `settings.json` сочетания хранятся как
«команда → клавиши».

Если ресивер отклоняет изменение (на его дисплее «Not Available» — например, Vocal Enhancer без
звукового сигнала или Late Night не на дорожке Dolby/DTS), регулятор в приложении возвращается к
прежнему значению.

`raw:NTCMODE` — кнопка MODE пульта: пока звук идёт с NET или Bluetooth, она показывает на экране
картинку с ранее выбранного видеовхода, повторное нажатие возвращает экран воспроизведения. Есть
кнопкой на вкладке «Сеть» и действием в списке горячих клавиш.

Ресивер держит одно управляющее соединение с одного компьютера: вторая программа управления на том же
ПК будет отбирать его у приложения. Приложение в таком случае переподключается всё реже и пишет об
этом в строке состояния.

## Подключение и сетевой интерфейс

Ресивер находится автопоиском; адрес можно задать и вручную. Настройка «Сетевой интерфейс»:

- **Авто** (по умолчанию) — соединяться только через адаптер, который в одной подсети с ресивером;
- **конкретный адаптер** — только через него;
- **Не привязывать** — путь выбирает Windows (нужно, если ресивер в другой подсети).

Привязка нужна, когда адрес ресивера перекрыт чужим маршрутом, например от VPN: без неё пакеты
уходят в туннель. В режимах с привязкой приложение никогда не подключается «в обход».

## Файлы

Настройки, кэш описания ресивера и журнал ошибок лежат в `%AppData%\OnkyoMaster`.

## Устройство кода

- `Protocol/` — кадры eISCP, автопоиск, соединение с очередью команд, разбор описания ресивера.
- `Model/` — наблюдаемое состояние ресивера и зон, команды.
- `Services/` — настройки, глобальные горячие клавиши, перехват команд громкости, автозапуск,
  канал команд между экземплярами.
- `UI/` — значок в трее, быстрая панель, панель управления, индикатор громкости.

Для проверки интерфейса без экрана: `OnkyoMaster.exe --snapshot <папка> [--wait сек] [--theme light|dark]`
подключается к ресиверу, сохраняет все окна в PNG и выходит. Перед этим закройте работающий
экземпляр (`OnkyoMaster.exe exit`), иначе они будут отбирать соединение друг у друга.
